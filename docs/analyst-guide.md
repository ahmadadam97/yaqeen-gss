# From question to decision

The seven required outputs answer different questions about the same interviews. Read the overlap audit first: 2016 appears in both files; year plus ID is the key. Then split by intent, not by a single universal complete-case filter.

| Required questions | Dependency | What to avoid |
|---|---|---|
| Q1 prayer by upbringing; Q2 afterlife by year | RELIG16 describes upbringing, PRAY describes practice and POSTLIFE describes a stated belief. Each can be answered without employment or media data. | Treating upbringing as current identity, or uncertainty as disbelief. |
| Q3 industry by degree; Q4 TV by work satisfaction; Q5 ever worked a year | Start with work status. Q3 and Q4 use current workers; Q5 uses nonworkers. Degree/industry are needed only for Q3; TV/satisfaction only for Q4. | Assuming every nonworker was asked about work history, or that a current worker necessarily worked a year. |
| Q6 media change; Q7 overlap | Compare repeated cross sections by wave using each item's eligible respondents. Q7 audits file membership before deduplication and the interview grain afterward. | Counting the shared wave twice or reading the three waves as the same people over time. |

**Why these extensions?** Yaqeen publishes research as well as videos and infographics. The JD asks for data models that researchers and product teams can use together. Query 10 connects a question about practice to one about belief without grading anyone's faith. Query 11 uses age and non-email web time to extend the newspaper question; the same respondents supply both measures. Neither query observes Yaqeen users, donations, format preference or learning. Use the results to design a follow-up, not to target people by faith. [Yaqeen's mission](https://yaqeeninstitute.org/about-us/our-mission).

**Weight choice (bonus 2.4).** Keep WTSSPS as the primary weight for continuity and WTSSNRPS as the nonresponse-adjusted sensitivity check for these waves. NORC's [FAQ](https://gss.norc.org/faq.html) names WTSSPS for most analyses; [methodological report 135](https://gss.norc.org/content/dam/gss/get-documentation/pdf/reports/methodological-reports/MR135%20poststratified%20weights.pdf) recommends WTSSNRPS for cross-sectional work in 2004 onward. Both are shown so the decision is inspectable. For each prayer group **within each wave**, divide the sum of positive weights for yes answers by the sum for valid yes/no answers with valid weights. A weight is never a respondent count; keep raw n alongside the estimate. Missing belief/weight goes in neither sum. The original required queries remain explicitly descriptive of the observed sample. The new estimates do not adjust for unanswered belief items. For population inference, acquire the matching strata and primary sampling unit fields (VSTRAT and VPSU), verify the survey universe and estimate design-based uncertainty. Don't average wave percentages without defining the target population and wave weighting.

**Panel practice.** Run queries 07, 10 and 11 yourself. Explain why ID alone loses interviews, reproduce a weighted percentage by hand (`1 yes of weight 1; 1 no of weight 3 = 25%`), and explain why unknown web time is different from zero. Finally, describe which data you would need before advising Yaqeen to change a content format. These are exercises, not claims about checks the candidate has completed.
