Models, columns, seeds and tests use lower snake case. The raw schema owns files and records. stg_membership stores the four extract membership keys. answers and respondents are analyst tables in DuckDB's main schema. Source variable names match NORC except for year and id_, exposed as survey_year and respondent_id. A _value suffix denotes a numeric value, _status explains response availability, _n denotes a count, _pct denotes a percentage and _pp denotes a percentage-point difference. source/sql uses numbered question names for stable display order. dbt/tests are named for the expectation they enforce.

To add a variable, select it in Explorer, append its domain, reviewed waves and wide projection flags to variables.csv and its exported CodeLabel entries to codebook.csv. The loader, overlap resolution and answers model already handle it. The wide_label, wide_value and wide_status flags generate the optional projections in respondents. Update eligibility.csv for a split item. A genuinely new wave needs questionnaire and routing review before its year is added. A newly absent field stays absent_field. Explicit .y is not_asked_year. Review new file versions against what was previously published.
